# 官方核验平台清单

所有核验必须回到**发证机构/主管机关的官方数据库**。厂商自己官网贴的证书图、电商详情页的资质截图，一律不算已核验。

- [零、官方平台打不开时怎么办（先读这一条）](#零官方平台打不开时怎么办先读这一条)

- [二、产品认证核验](#二产品认证核验)（CCC / 食品 / 医疗器械 / 化妆品 / 检测报告）
- [三、宣传合规性判读](#三宣传合规性判读)

- [核验结论写作规范](#核验结论写作规范)

**通用纪律：**
- 核验结果要记下**可复核的标识**（注册号/证书编号/统一社会信用代码），并在结论中写出编号，方便用户自己再查一遍。
- 查不到 ≠ 造假。可能是名称写法差异（简称 vs 全称）、数据更新延迟、或平台改版。查不到时先换关键词重试，仍查不到才标注"未检索到"。
- 记录核验时间。资质会过期、会被撤销。

## 零、官方平台打不开时怎么办（先读这一条）

**这些政府站点在部分网络环境下不可达**（实测：`www.gsxt.gov.cn`、
`cx.cnca.cn`、`nmpa.gov.cn`、`www.12315.cn` 在某些网络下会
`URLError` / 超时）。资质核验是**不可协商**的步骤，所以必须先有降级预案，
否则要么空转、要么违规用商业数据商顶替。

**降级动作，按顺序执行：**

1. **换入口**：优先带完整路径而非裸域名——
   `www.gsxt.gov.cn/index.html`、`cx.cnca.cn/CertECloud/index/index/page`、
   `www.nmpa.gov.cn/datasearch/home-index.html`。
   再试**省级分站**（如 `gd.gsxt.gov.cn`）、或该平台的**移动端/小程序**入口。
2. **换通道**：用无头浏览器（见「抓取实操方案」文件）打开同一地址，
   很多情况下 HTTP 直连被拦但浏览器可读。
3. **换检索方式**：在通用搜索引擎检索
   `site:gsxt.gov.cn {企业全称}`，或 `{证书编号} CCC 查询`，
   读取**搜索结果摘要**。
4. **强制标注**：如果只拿到摘要、没进到官方页面本体，
   结论里**必须**写成"（仅检索到摘要，未完成官方页面核验）"，
   **不得**直接写"已核验通过"。
5. **兜底话术**：以上都不行时，明确告诉用户
   "官方核验平台当前在你这边可能打不开，请自行访问 X 确认 Y 编号"，
   把核验动作交还给用户，而不是假装查过了。

**红线**：企查查 / 天眼查等商业数据商**只能用于找线索**，
不能作为"已核验"的最终依据（信息滞后、口径不同）。绝不能因为官方
站打不开，就用商业数据商的结果冒充官方核验结论。

## 一、厂商主体核验

### 国家企业信用信息公示系统
- 入口：`www.gsxt.gov.cn/index.html`（国家市场监督管理总局主办，唯一权威出处）
- 备用：省级分站（如 `gd.gsxt.gov.cn`）；打不开时按**第零节**降级
- 可查：企业基本信息、股东、注册资本与实缴、经营范围、分支机构、变更记录、年报
- 可查风险信息：**经营异常名录、严重违法失信名单、行政处罚、抽查检查结果**
- 判读要点：
  - **注册资本 ≠ 实缴资本**。认缴制下注册资本是承诺出资额，看"股东及出资信息"里的实缴情况才有意义
  - **成立时间**：宣称"二十年老牌"但成立于 2022 年的，直接判定宣传不实
  - **经营范围**：卖食品的没有食品经营许可范围、卖医疗器械的不含相关经营范围的，是实质性问题
  - **经营状态**：注销、吊销、存续 —— 注销状态下还在卖货，售后主体已经不存在了
  - **注册地址**：与宣称的厂址、办公地是否一致

### 其他主体信息补充渠道
| 平台 | 用途 | 注意 |
|---|---|---|
| 企查查 / 天眼查 | 快速看风险摘要、关联企业、司法案件 | 商业数据商，信息有滞后，**最终以公示系统为准** |
| 中国裁判文书网 | 查产品质量纠纷、合同诉讼 | 能看出厂商是否频繁被诉质量问题 |
| 中国执行信息公开网 | 查是否失信被执行人、限制高消费 | 失信企业有跑路风险 |
| 12315 平台 / 黑猫投诉 | 查消费投诉量与处理率 | 投诉量大且解决率低是强负面信号 |
| 工信部 ICP/IP 备案系统（`beian.miit.gov.cn`） | 查官网备案主体 | 官网宣称主体与备案主体不一致 = 实际经营主体存疑 |

## 二、产品认证核验

### 全国认证认可信息公共服务平台（CNCA）
- 入口：`cx.cnca.cn/CertECloud/index/index/page`（国家认证认可监督管理委员会）
- 打不开时按**第零节**降级（换省级节点、无头浏览器、`site:cx.cnca.cn` 检索）
- 这是**认证证书的统一核验入口**，可查：
  - 强制性产品认证（CCC）
  - 自愿性产品认证
  - 管理体系认证（ISO 9001 / ISO 14001 等）
  - 获证企业、证书编号、发证机构、**证书状态与有效期**
- 判读要点：
  - 重点看 **证书状态**：有效 / 暂停 / 撤销 / 注销。企业宣传时往往用已撤销的历史证书
  - 核对**证书上的产品型号**是否与在售型号一致 —— 认证是按型号发的，一款过了不代表全系过了
  - 核对**发证机构**是否为正规认证机构

### CCC 强制性产品认证
- 适用范围：电线电缆、家用电器、电子产品、玩具、汽车零部件、消防产品等（目录内产品**未获 CCC 不得在国内销售**）
- 核验方式：通过 CNCA 平台按证书编号或企业名称查询
- 判读要点：CCC 是**准入门槛**而非质量等级。有 CCC 只说明合规，不代表质量好。但**没有 CCC 而属于目录内产品 = 违规销售**

### 食品相关
- **生产许可 SC 编号**：`sc` 前缀 + 14 位数字，前 3 位为食品类别码
- 核验：国家市场监督管理总局 → **食品生产许可获证企业查询**
  （`www.samr.gov.cn` 下的"服务"→"食品生产许可查询"入口；
  打不开时按**第零节**用 `site:samr.gov.cn {SC编号}` 检索）
- 判读要点：SC 编号要与包装上标注的生产商一致；分装产品要看原产商资质

### 医疗器械
- 核验入口：**国家药品监督管理局** 数据查询平台
  （`www.nmpa.gov.cn/datasearch/home-index.html` → 医疗器械 → 国产/进口器械注册）
- 打不开时按**第零节**降级，用 `site:nmpa.gov.cn {注册证编号}` 检索
- 可查：注册证编号、产品名称、注册人、有效期、管理类别（I/II/III 类）
- 判读要点：
  - 注册证编号格式如"国械注准 202XXXXXXX"，要逐位核对，造假常在这一串数字上做手脚
  - **I 类备案 ≠ II/III 类注册**，把备案说成"国家注册认证"是常见的夸大
  - 核对注册证上的**适用范围**——宣称的疗效/功能超出注册证范围的，属于虚假宣传（如普通理疗仪宣称能治病）

### 化妆品
- 核验入口：国家药监局 → 化妆品备案/注册信息
- 特殊化妆品（防晒、美白、染发、烫发、防脱发）需**注册**，普通化妆品为**备案**
- 判读要点：宣称"特殊功效"但只有普通备案的，是违规宣传

### 检测报告（CMA / CNAS）
- **CMA**（检验检测机构资质认定）：报告上有 CMA 标志才具有法律效力
- **CNAS**（实验室认可）：国际互认，但**不替代 CMA**
- 核验：报告上必须有**报告编号**和**检测机构名称**，到该机构官网或 CNCA 平台核对编号真伪
- 判读要点：
  - 厂商自己实验室出的"报告"，无第三方 CMA 资质，不具证明力
  - 送检样品 ≠ 量产产品。经销商送检的"样品合格"不能代表市售批次
  - 核对**检测项目**是否覆盖宣传卖点 —— 宣传了防水却在报告里找不到防水项，即无依据

## 三、宣传合规性判读

### 绝对化用语（《广告法》第九条）
"国家级""最高级""最佳""第一""顶级""绝无仅有"等 —— 除非有合法依据，否则属于违法广告。看到即视为**宣传不可信信号**。

### 其他常见虚假宣传形态
| 话术 | 问题 |
|---|---|
| "国家认证" / "权威认证" | 未指明具体证书编号，无法核验 |
| "XX 机构推荐" | 需核对机构是否存在、是否有推荐资格 |
| "德国/日本技术" | 需区分"技术来源""原料来源""产地"，很多是授权贴牌 |
| "原价 999 现价 99" | "原价"须为真实成交过的价格，否则属价格欺诈 |
| "销量第一" | 需有可验证的数据来源与统计口径 |
| "专家推荐""医院同款" | 需核对专家身份、是否存在代言关系 |
| "包治""根治""无副作用" | 医疗/保健类明确违规 |
| 保健食品宣称治病 | 保健食品不是药品，宣称疗效即违法 |

### 价格宣传核验
- "历史最低价"：用第三方价格追踪工具核对历史曲线
- "全网最低"：多平台比价，注意是否用"电商专供款"低价款对比正价款
- 促销"倒计时"：多为常驻组件，不构成真实时限

## 四、海外销售时的补充核验

如果商品涉及跨境购买或海外品牌，需额外核对：

| 认证 | 适用 | 核验入口 |
|---|---|---|
| FDA | 美国食品/药品/医疗器械/化妆品 | `fda.gov` 数据库 |
| CE | 欧盟市场准入 | 欧盟 NANDO 数据库（查公告机构） |
| FCC | 美国无线电/电磁兼容 | `fcc.gov` ID 查询 |
| UL / ETL | 北美安规 | UL Product iQ |
| EPA | 美国杀虫剂/环保 | `epa.gov` |

判读要点：CE 是**自我声明**为主，无统一官方数据库，且需注意公告机构是否具备该产品类别的授权范围。商家给出的"CE 证书"可能来自无授权的机构。

## 核验结论写作规范

**不要写：**
> "该品牌资质齐全，认证齐全，可以放心购买。"

**要写：**
> 主体：XX 有限公司，2019 年成立，注册资本 500 万（公示系统未见实缴），
> 状态存续，近三年无行政处罚与经营异常记录。
> 产品认证：CCC 证书编号 20XXXXXXXXXXXX，CNCA 平台可查，状态有效，
> 覆盖在售型号 XX-200。
> 未核验到项：宣传中提及的"德国 TÜV 认证"未在宣传页给出证书编号，无法核验。
> 核验时间：2026-09-22。

每条核验结论都要包含：**结论 + 可复核标识 + 未核验项 + 核验时间**。
