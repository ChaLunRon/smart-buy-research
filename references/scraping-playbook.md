# 受限平台获取方案（爬取手册）

**本文件在需要爬取时才读。** 日常调研优先走 SKILL.md 的「换源」路线，不要一上来就爬。

**执行顺序纪律（不可改变）：**

```
换源 → 换检索形态 → 爬虫 → 用户协作
```

---

## 零、两个独立难题：找社区 ≠ 读社区

**这是实测算出来的教训，必须分开处理。**

| 难题 | 表现 | 对策 |
|---|---|---|
| **找社区** | 不知道某品类有没有专业社区 | 搜 `{品类} 论坛` `{品类} 哪个网站专业`；查 sources-map 第五节对照表 |
| **读社区** | 知道社区名字，但页面读不到内容 | 本文件下面的方案一~四 |

**实测案例**：定位到 Chiphell / 本友会 / NGA / PCEVA 后，**只有 Chiphell 的帖子能直接读到内容**，其余只拿到搜索引擎摘要。

**纪律**：
- **"我找到了专业社区"≠"我读到了专业社区的内容"**，绝不在结论里把两者混为一谈
- 只读到摘要时，结论里标注 **（仅摘要）**
- 摘要只能用于判断方向，不能用来支撑具体结论

## 一、MediaCrawler（覆盖最广，推荐）

**GitHub: `NanmiCoder/MediaCrawler`** —— 约 56.9k stars，2026-09 仍活跃更新。

### 覆盖能力

| 平台 | 关键词搜索 | 指定帖子 | 二级评论 | 创作者主页 |
|---|---|---|---|---|
| 小红书 | ✅ | ✅ | ✅ | ✅ |
| 抖音 | ✅ | ✅ | ✅ | ✅ |
| 快手 | ✅ | ✅ | ✅ | ✅ |
| B站 | ✅ | ✅ | ✅ | ✅ |
| 微博 | ✅ | ✅ | ✅ | ✅ |
| 贴吧 | ✅ | ✅ | ✅ | ✅ |
| 知乎 | ✅ | ✅ | ✅ | ✅ |

**为什么它有价值**：唯一能系统性解决"小红书/知乎/贴吧读不到"的开源方案，**且支持关键词搜索**（不只是抓指定链接）。

### 使用要点

```
依赖: uv + Node.js >= 16 + Chrome >= 144
运行: uv run main.py --platform xhs --lt qrcode --type search
登录: 扫码登录，CDP 模式复用已有 Chrome 登录态（大幅降低风控风险）
输出: CSV / JSON / Excel / SQLite
注意: 需在 60 秒内点击 Chrome 弹出的接受对话框
```

### 风险与合规（必须向用户说明）

- 项目声明**仅限学习用途、禁止商用**
- 平台有风控（抖音已挂 ArgusSecurityPlugin 网关）
- **必须串行、保守频率**，不要并发
- **不建议在重要账号上使用**，扫码登录存在账号风险

## 二、微信公众号

**公号内容无公开网页入口，必须走专用工具。**

| 项目 | 能力 |
|---|---|
| `qbu11/wechat-article-spider` | `login` / `search` / `scrape`；可指定公众号名、页数、天数，导出正文 |
| `ghh1251/wechat_articles_spider` | 按关键词在历史文章中检索并加权排序 |

**关键限制**：需要**注册一个自己的微信公众号账号**才能登录 MP 平台。免费但需手机验证。**切勿使用重要账号。**

**替代**：搜狗微信搜索只能拿到近期少量文章，不适合完整调研，不建议依赖。

## 六、电商平台（京东/淘宝/拼多多）的反爬与比价

**这一节与 `price-and-channel.md` 配合使用。**

### 反爬情况

| 平台 | 反爬强度 | 常见表现 |
|---|---|---|
| 京东 | 中 | 价格可直接读到；"问大家"需登录；商品页偶发拦截 |
| 淘宝/天猫 | **高** | 商品页、评价页基本需要登录；滑块验证频繁 |
| 拼多多 | **高** | 网页版功能残缺，主要走 App；"问大家"与评价需登录 |

**所以：电商平台优先走"用户截图协作"，而不是硬爬。** 用户自己打开页面截图，成本最低、信息最真。

### 可用的开源方案（GitHub 调研结果）

**方案一：maishou 比价工具（覆盖最广）**

- **GitHub: `aahl/skills` 的 `maishou` skill** —— 约 153 stars，2026-07 更新
- 覆盖：淘宝/天猫、京东、拼多多、苏宁、唯品会、考拉、抖音、快手、1688
- 命令：`uv run scripts/main.py search --source=0 --keyword='{关键词}'`
- `source` 参数：`0` 全部 / `1` 淘宝天猫 / `2` 京东 / `3` 拼多多 / `4` 苏宁 / `5` 唯品会 / `6` 考拉 / `7` 抖音 / `8` 快手 / `10` 1688
- 依赖：Python ≥3.11、uv、aiohttp
- **⚠️ 风险**：依赖**非官方第三方 API**（appapi.maishou88.com），安全审计未全绿。**使用前必须告知用户并取得同意**，不要静默调用。

**方案二：PriceLens（本地优先，隐私最好）**

- **GitHub: `wuliao00/PriceLens`** —— MIT 开源，双端（Android + Windows Electron）
- 能力：京东/淘宝/拼多多商品页自动读价、历史价格曲线、优惠券一键复制、B站翻车/推荐视频识别
- 兜底源：识货（shihuo.cn）、什么值得买、慢慢买、购物党
- **优势**：数据不出本机、无埋点、本地优先。**注意这是客户端工具，需要用户自己装，不是我能直接调的**

**方案三：慢慢买历史价格（有逆向参考）**

- **GitHub: `PPsteven/manmanbuy_js_crack`** —— 慢慢买比价爬虫的 JS 逆向破解过程记录
- 价值：慢慢买聚合淘宝/京东/天猫/拼多多历史价格，是识别"先涨后降"虚假促销的好工具
- 接口形态：`POST http://tool.manmanbuy.com/api.ashx`，参数含 `method=getHistoryTrend`、商品链接、时间戳、token
- **注意**：慢慢买自身有反爬（token + 时间戳 + BasicAuth），该项目的价值在于**记录了破解思路**，不是开箱即用

**方案四：xiaxiayouhui-deals（只读 API，最干净）**

- 服务地址 `https://xiaxiayouhui.xyz/api/skill/v1/*`，MIT 开源，有 ICP 备案
- 接口：`compare`（跨平台比价）、`coupon`（找券）、`parse-link`（链接口令解析）、`daily-deals`（今日好价）
- 声明仅读官方公开数据、不收集用户数据
- **注意**：本质是第三方服务，可用性依赖其运营状态

### 使用顺序（电商比价）

```
用户截图（最可靠，首选）
  ↓
PriceLens / 比价客户端（用户自己装，隐私好）
  ↓
maishou / xiaxiayouhui（第三方 API，需用户同意）
  ↓
慢慢买逆向方案（技术门槛高，仅在必要时）
```

**核心纪律：电商数据的可信度优先级是"用户自己看到的" > "工具抓到的"。** 券和补贴这类会变的信息，永远让用户自己在页面上确认。
