## 示例 1：性价比型 · 学生笔记本

**输入**

```
我是大一新生，计算机大类专业，男生，需要买大学用的电脑，
我对电脑一无所知，预算大概 6000。
```

**输出**（约 300 字，四块结构）

> **买 ThinkBook 14+ 2026，5000-6500 档。**
>
> 理由：
> - 32G 内存 + 1T 硬盘，计算机专业四年够用
> - 接口全（有网口），宿舍网络差时很实用
> - 同价位里标配最全，做工公差稳定
>
> 到手约 ¥5xxx，京东自营。
>
> **坑**：网卡可能随机装配廉价型号导致掉线。买前问清是不是 Intel 网卡；若中招，自己换一块约 70-100 元。
>
> 还想知道什么？

**过程中发生了什么（用户看不到，但 Skill 强制要求）**

1. **必要性问题**：学习刚需 → 通过，继续
2. **知识水平判断**：「对电脑一无所知」→ 折叠 3-5 个术语铺底（内存/硬盘/网口）
3. **垂直社区定位**：搜「笔记本 论坛」→ Chiphell、NGA 硬件区，作为主信息源
4. **黑名单过滤**：丢弃门户内容农场结果
5. **差评规律挖掘**：反复出现的「网卡掉线」→ 升级为「最大的坑」
6. **交叉验证**：该结论来自 ≥2 个独立平台

## 示例 2：危重型 · 保健品

**输入**

```
想给我妈买个补钙的，什么牌子好？
```

**输出**（危重型 → 强制资质核验 + 必要性拷问）

> **先别急着买。**
>
> 理由：
> - 补钙前建议先查血钙和骨密度，缺不缺不一样
> - 真正有用的是「维 D + 钙」同补，单补钙吸收有限
>
> 如果要买，看**每片有效成分单价**，不看瓶身价格。
>
> **坑**：市面上大量「高钙」产品实测含量与标注不符。优先选有第三方实验室检测的（Labdoor / ConsumerLab 可查）。
>
> 补钙属于健康决策，具体剂量请咨询医生。

**Skill 做了什么**

- **必要性拷问**：保健品是重点「伪需求」品类 → 先问体检指标
- **资质核验强制**：危重型必须走完整流程
- **国际独立源**：Labdoor / ConsumerLab 查成分实测
- **边界声明**：明确不提供医疗建议

## 示例 3：劝退 · 必要性拷问

**输入**

```
最近看到很多人用那个降噪耳机，有点想买，就是有点纠结。
```

**输出**（第一句就给结论：别买）

> **建议先别买。**
>
> 理由：
> - 你说的是「看到别人用」，不是「现有耳机不够用」
> - 「有点纠结」通常就是不必要
>
> 加购物车放 3 天。如果三天后还想要，我们再聊选哪个。
>
> 现在不买能省 ¥1500 左右。

**Skill 做了什么**

- 识别「情绪型 + 犹豫表述 + 从众动机」三个信号 → 触发必要性拷问
- 不给选品内容（劝退就劝退，不硬推）
- 给出**省下多少钱**（量化收益）

## 示例 4：已购诊断

**输入**

```
双十一买的 XX 笔记本已经用了一个月，看网上说这型号有问题，我被坑了吗？
```

**输出**（先别吓用户）

> **先别慌。**
>
> 情况：
> - 你买的是标准款，不是电商专供缩水版
> - 网上说的问题是**特定批次**的，你的批次不在其中
>
> 建议：
> - 机器一个月没问题，继续用
> - 留意一个症状：屏幕偶尔闪一下（该批次已知问题）。真出现就走保修
>
> **保修期内，无需焦虑。**

**Skill 做了什么**

- 已购模式**流程精简**，重点从「选什么」变为「有没有踩坑」
- `核验三件事`：型号批次 / 已知批量问题 / 保修状态
- 明确**不制造恐慌**：有问题直说，没问题也要给确认

## 示例 5：识别恰饭测评

**输入**

```
我看到一篇 XX 的评测把它吹上天，这个能信吗？
```

**输出**

> **大概率是软广，别当依据。**
>
> 判断依据（命中 3 条以上）：
> - 通篇没有实质缺点，只提了无关痛痒的（"重了一点点"）
> - 发布时间与大量同类好评集中在一两天内
> - 结尾挂了购买链接
>
> 换 C 站拆解视频 + 黑猫投诉交叉看。要我查一下吗？

**Skill 做了什么**

- 四层信号识别：**文本层 / 账号层 / 时间层 / 图片层**
- 时间层信号被标为「最有效」：好评集中发布 → 整批剔除
- 不直接下最终判断，给方向并询问是否继续深挖
