# 信息源地图

记录各平台的特点、适合挖什么、检索技巧、以及样本可信度的基准评级。

**可信度评级的含义**：是指"这个平台的单条内容平均有多可信"，不是指平台本身的好坏。低可信度平台里同样有高质量长测，只是需要更多过滤。

---

## 一、社交内容平台

### 小红书
- **特点**：消费决策第一入口，覆盖品类最广（美妆、家居、母婴、数码、穿搭）。图文为主，视觉化强。
- **适合挖**：真实开箱、日常使用细节、颜值与做工评价、同价位横评
- **商业污染程度**：**极高**。笔记带货、品牌合作、置换测评占比很大
- **检索技巧**：
  - 加"无广""自费""真测评"等词，能一定程度筛掉合作内容
  - 按"最新"排序看近期真实反馈，而非按热度
  - 评论区比正文更真实 —— 尤其看有没有人质疑"是不是广告"
  - 关键词加"拔草""翻车""后悔"
- **可信度基准**：★★☆☆☆（单条）；★★★★☆（多篇不同作者交叉印证后）
- **特别提醒**：图文过于精美、光线布置专业、必挂购买渠道的，基本是商单

### 知乎
- **特点**：长文分析为主，参数与技术讨论密度高。
- **适合挖**：原理分析、参数解读、深度横评、行业内部视角
- **商业污染程度**：**高**。"好物推荐"卡片是直接变现通道
- **检索技巧**：
  - 看"赞同"之外的**评论区**，高赞回答的评论区常有专业反驳
  - 关注答题者的背景（是否与品类相关专业）
  - 警惕"列举大量参数但无实测"的回答 —— 多为复制官方资料
- **可信度基准**：★★★☆☆

### B站
- **特点**：视频形式，能展示实际操作与拆解，信息维度最丰富（外观、声音、手感、拆机）。
- **适合挖**：拆解测评、长期使用 vlog、实测对比
- **商业污染程度**：中高（恰饭视频会标注或不标注，需自行判断）
- **检索技巧**：
  - 优先看**拆解类**和**长测类**视频，商业价值低，客观性强
  - 看弹幕和评论区，观众对恰饭的识别往往很准
  - 注意"播放高但评论少"的异常
  - 看 UP 主历史内容是否长期专注该品类（专注可以是专业，也可以是厂商号）
- **可信度基准**：★★★☆☆；拆解/长测类可达 ★★★★☆

### 微博
- **特点**：舆论场，热点爆发快。
- **适合挖**：品牌舆情、翻车事件、维权曝光、售后纠纷
- **商业污染程度**：中（官方号运营规范，但水军控评普遍）
- **检索技巧**：配合"超话"看真实用户聚集地；搜"品牌名+维权/投诉/翻车"
- **可信度基准**：★★☆☆☆
- **特别提醒**：微博是观察"品牌如何处理危机"的最佳场所，翻车后的公关态度本身是重要参考

### 抖音
- **特点**：短视频，传播力强，种草效率高。
- **适合挖**：产品实际使用场景、上手体验
- **商业污染程度**：**极高**。带货是核心商业模式
- **检索技巧**：看评论区"翻车"追问；搜"品牌名+缺点"
- **可信度基准**：★★☆☆☆
- **特别提醒**：抖音内容高度娱乐化，时长限制导致信息深度不足，**不建议作为主要信息源**

### 什么值得买（SMZDM）
- **特点**：购买导向的平台，以价格爆料和值友评测为核心。
- **适合挖**：历史价格、促销时机、到手价对比、值友实测
- **商业污染程度**：中（有商家合作内容，但值友社区文化对虚假宣传容忍度低）
- **检索技巧**：看"值"和"不值"的投票比例；评论区常有人纠正夸大宣传
- **可信度基准**：★★★★☆（价格信息）；★★★☆☆（评价信息）
- **特别提醒**：是**比价的最佳信息源**，价格爆料有历史记录

### 贴吧 / 豆瓣小组
- **特点**：垂直社区，用户粘性高，讨论深入。
- **适合挖**：长期使用问题、品牌通病、小众品类的真实口碑
- **商业污染程度**：低
- **检索技巧**：进品牌专属吧/小组看置顶的"问题汇总"帖
- **可信度基准**：★★★☆☆
- **特别提醒**：样本量小、用户偏好强烈，结论要标注"垂直社区观点，样本有限"

### 黑猫投诉 / 12315 平台
- **特点**：消费投诉公开平台。
- **适合挖**：售后纠纷、批量质量问题、厂商处理态度
- **商业污染程度**：低
- **检索技巧**：看**投诉解决率**而非投诉数量；大品牌销量大，投诉绝对数自然高
- **可信度基准**：★★★★☆
- **特别提醒**：投诉内容需甄别（有恶意投诉），但**同一问题反复出现**是强信号

## 二、电商平台

| 平台 | 优势 | 检索技巧 | 注意 |
|---|---|---|---|
| 淘宝 / 天猫 | 品类最全，中小品牌多 | 看"问大家"板块（真实买家问答，难以控评）；筛选"追评"看长期使用 | "问大家"是电商平台里最接近真实的信息源 |
| 京东 | 自营售后规范，物流快 | 看自营 vs 第三方；看"商品评价"中的差评与追评 | 自营与第三方的售后责任主体不同 |
| 拼多多 | 价格低 | 注意"百亿补贴"是否有官方授权；查店铺资质 | 白牌与山寨风险高，"电商专供款"多 |
| 抖音商城 | 直播带货 | 注意直播话术夸大 | 冲动消费风险高，慎选 |
| 唯品会 | 品牌特卖 | 注意是否当季款 | 部分为过季或特供款 |
| 苏宁 / 国美 | 家电 3C | 适合大件家电比价 | — |

**电商评价的读法（关键）：**
- **"问大家"优先级最高** —— 由买家回答买家问题，商家难以系统性控评
- **追评优先于首评** —— 首评多为开箱情绪，追评才有使用后的真实判断
- **差评要读全文** —— 很多差评是物流问题（与产品无关），要区分"产品问题"和"服务问题"
- **看差评率而非差评数**
- **注意"默认好评"失真** —— 电商好评率普遍虚高，参考价值有限

## 四、检索策略

### 跳出商业内容池
搜索结果前几页往往被 SEO 优化的商业内容占据。跳出方法：
1. **改变关键词的情绪色彩**：加"后悔""避雷""智商税""翻车""维权"
2. **站内搜索**：直接进垂直社区站内搜，绕开搜索引擎的商业排序
3. **按时间排序**：商业长文的权重会随时间衰减，"最新"更接近真实
4. **搜索长尾问题**：搜 `{型号} 用了一年` `{型号} 故障` 而非 `{型号} 评测`
5. **搜索负面组合**：`{品牌} 投诉` `{品牌} 售后` `{品牌} 骗局`

### 关键词模板速查

| 目的 | 关键词模板 |
|---|---|
| 建立候选池 | `{品类} 推荐` `{预算}元 {品类}` `{品类} 横评` |
| 挖缺点 | `{型号} 缺点` `{型号} 问题` `{型号} 后悔` |
| 挖长期体验 | `{型号} 一年后` `{型号} 长期使用` `{型号} 寿命` |
| 挖品牌舆情 | `{品牌} 翻车` `{品牌} 投诉` `{品牌} 售后经历` |
| 查资质 | 直接进官方平台按企业名称/证书编号检索 |
| 比价 | `{型号} 到手价` `{型号} 历史价格` `{型号} 值得买` |

### 交叉验证规则

| 结论类型 | 最低独立来源数 | 说明 |
|---|---|---|
| 致命缺陷（安全、批量故障） | 3 | 且需含带证据来源 |
| 产品级缺陷（续航、发热） | 2 | 需来自不同平台 |
| 品牌级判断（售后差） | 2 | 优先采用投诉平台数据 |
| 个人偏好类（颜值、手感） | 1 | 明确标注为主观 |

未达标的结论必须标注"**样本不足，倾向性判断**"。
