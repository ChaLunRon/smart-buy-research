# 品类专属避坑小抄

通用方法论解决不了品类专属的陷阱。本文件收录各品类的**专属避坑要点**——即"这个品类最容易被忽悠的地方"。

**使用方式**：Step 0.5 识别品类后，先读对应小抄，把其中的要点作为额外的检索方向和判断标准。小抄内容不是结论，是**检查清单**。

---

## 保健品 / 膳食补充剂

**这个品类是全品类里伪需求密度最高的。** 大量产品本质上是安慰剂，且营销话术极其成熟。

### 必要性拷问（本品类必做）
先问：**"你体检有相关指标异常吗？"**
- 没有 → 优先劝退。健康人体内多数营养素自合成充足（辅酶 Q10、胶原蛋白等），额外补充效果存疑
- 有 → 按医嘱，本技能只做产品层面的信息核验

### 核心陷阱

**陷阱一：用总重量掩盖有效成分含量**
- "1800mg 4倍高浓度鱼油" —— 1800mg 是**鱼油总量**，不是 ω-3 含量
- 真正该比的是 **ω-3 单价**（元/g），以及 EPA/DHA 的具体比例
- 正确算法：`价格 ÷ ω-3 含量(g)`，而不是 `价格 ÷ 胶囊重量`

**陷阱二：假洋牌**
- 宣称"挪威""德国""澳洲"品牌的，核对其实际注册主体
- 常见套路：国内公司在海外注册空壳商标，回国营销为"进口品牌"
- 实例：被媒体点名的"NYO3 挪威品牌"，实际为青岛某公司注册
- **核验方法**：查商标注册人、查企业主体的注册地（见 `official-registries.md`）

**陷阱三：剂型与吸收率的营销**
- rTG 型 / EE 型 / TG 型确实是真实差异，但"吸收率高 X 倍"的说法通常有夸大
- 优先看**第三方实测**（Labdoor、ConsumerLab、IFOS），不看厂商宣传

**陷阱四：检出重金属/有害物质**
- 保健品的重金属（铬、铅、砷）超标是历史高发问题
- **检索方向**：`{品牌} 重金属` `{品牌} 抽检` `{品牌} 消费者报道`
- 已知有被检出问题的品牌应直接列入不推荐

**品类的必备核验**：保健食品标志（蓝帽子）、批准文号、生产企业的 SC 编号。宣称治病疗效的保健食品属明确违规。

## 数码 / 3C / 电子产品

### 核心陷阱

**陷阱一：电商专供款 / 特供型号**
- 同型号不同后缀（如 XX-100 与 XX-100A）可能是简化配置版本
- 内存、屏幕、闪存颗粒、散热可能缩水，且与评测机型不一致
- **核验方法**：核对商品参数页的完整型号，与评测/官网参数逐项比对

**陷阱二：参数竞赛制造的无效溢价**
- 屏幕刷新率从 120Hz 到 144Hz，多数人感知不到
- 相机像素数不代表成像质量，传感器尺寸和算法更重要
- 处理器跑分不代表日常流畅度，散热和调度才是
- **判断准则**：这个参数优势在你的使用场景里能被感知吗？

**陷阱三：新品溢价与首发风险**
- 首发批次品控问题概率高于成熟批次
- 新品缺乏长期可靠性数据，差评少不等于质量好
- 通常建议等 2-3 个月，等首批真实反馈出来

**陷阱四：翻新机 / 水货 / 山寨同款混入**
- 明显低于市场价的要警惕
- 港版/美版无国内保修，代价可能超过省下的钱
- 查序列号可验真伪的品类（手机、相机）务必核对

**陷阱五：续航虚标**
- 厂商标称续航通常是理想条件（低亮度、关功能）
- 实际续航以**长测反馈的中位数**为准，不看标称值

### 检索优先级
Chiphell（硬核玩家，对虚标零容忍）> RTINGS（视听设备量化测试）> B站拆解视频 > 中关村在线 > 社交平台

### 该看什么
- **长期使用反馈**：一年后的电池衰减、发热、断连
- **拆解视频**：能看到用料和做工真相
- **售后记录**：黑猫投诉的解决率

## 家电 / 厨房电器

### 必要性拷问（改善型小家电必做）
问：**"你一周会做几次饭 / 会用几次？"**
- 空气炸锅、破壁机、早餐机、酸奶机、面包机 —— 冲动购买率与闲置率双高
- 如果答案是"偶尔""周末可能"，大概率会闲置

### 核心陷阱

**陷阱一：容量虚标**
- "5L" 可能是外机容量而非有效容积
- 冰箱看**有效容积**，不看总容积

**陷阱二：噪音参数不可比**
- 不同厂商测试距离和条件不同，dB 数值不可直接横向对比
- 以用户实测反馈为准

**陷阱三：安装与耗材的隐性成本**
- 需要安装的家电（洗碗机、油烟机、净水器）要算安装费、改水电费用
- 耗材类（净水滤芯、扫地机耗材）要看**长期使用成本**，机器便宜可能靠耗材赚钱

**陷阱四：能效等级的实际影响**
- 一级能效与三级能效的电费差，需要按实际使用频率估算
- 低频使用的电器，能效差价的回收周期可能超出产品寿命

### 售后要点（家电尤其重要）
- 大件看**上门服务覆盖范围**，寄修对用户是灾难
- 核对保修年限与保修范围（压缩机/电机是否单独保修）
- 看真实用户的上门维修经历

## 母婴 / 儿童用品

**本品类特殊性：安全绝对优先于性价比。此品类必须完成资质核验。**

### 必备核验
- **CCC 强制认证**：玩具、儿童安全座椅、童车等目录内产品必须有
- **核对认证覆盖的型号与年龄段**
- **市场监管总局抽检公告**：母婴品类抽检频率高，必查
- **召回记录**：儿童用品召回是重大风险信号

### 核心陷阱

**陷阱一：安全座椅按"年龄"而非"体重/身高"选**
- 安全座椅应以**体重和身高**为选择依据，年龄只是参考
- 不同固定方式（ISOFIX / 安全带）适配不同车型

**陷阱二：玩具的小零件与材质风险**
- 3 岁以下玩具的**小零件脱落**是窒息风险
- 塑化剂（邻苯二甲酸酯）超标是历史高发问题
- 涂料重金属超标

**陷阱三：婴儿食品与护肤品的安全**
- 看 SC 生产许可、看配方表
- 警惕宣称"纯天然""无添加"但无检测依据的

**陷阱四：二手用品的安全边界**
- 二手安全座椅（有碰撞史不可用）、二手奶瓶（材质老化）、二手玩具（小零件缺失）都应避免

### 输出要求
本品类的结论必须包含：**"涉及安全，最终以官方认证文件与检测报告为准"**，且不可给出"放心买"这类担保性表述。

## 美妆 / 护肤 / 个护

### 必备核验
- **化妆品备案/注册编号**：特殊化妆品（防晒、美白、染发、烫发、防脱发）需**注册**，普通化妆品为**备案**
- 宣称特殊功效但只有普通备案的，属违规
- 核对备案编号与国家药监局数据库

### 核心陷阱

**陷阱一：成分表做文章**
- 有效成分排在成分表越后，含量越低（成分表按含量降序排列）
- "添加了 XX 精华"不等于含量有效
- 看**浓度**和**配方体系**，不看成分表长度

**陷阱二：功效宣称无依据**
- "7 天美白""28 天淡纹"等具体时效承诺，需看是否有临床数据
- 多数是营销话术

**陷阱三：刷单重灾区**
- 美妆是刷单最密集的品类之一
- **必须用时间分布法检查**（见 `review-analysis.md` 的时间层信号）
- 关注"肤质不匹配"的差评，而非笼统好评

**陷阱四：假货与分装**
- 第三方店铺的低价大牌美妆假货风险高
- 优先官方渠道

### 该看什么
- **同肤质用户的反馈**（干皮/油皮/敏感肌完全不同）
- **使用周期长的反馈**（护肤品见效需时间）
- **过敏/刺激的反馈**（安全性问题）

## 食品 / 生鲜

### 必备核验
- **SC 生产许可编号**（14 位，前 3 位为食品类别码）
- SC 编号与包装标注的生产商应一致
- 分装产品看原产商资质

### 核心陷阱

**陷阱一：配料表文字游戏**
- "×× 味"（如"牛肉味"）≠ 含该成分
- "0 蔗糖"不等于无糖（可能有其他糖类）
- "不含防腐剂"可能是靠高盐高糖防腐

**陷阱二：产地与等级的模糊表述**
- "进口原料"不等于"进口产品"
- 等级标准（如特级、一级）要看具体国标

**陷阱三：保质期与临期**
- 大促低价可能是临期商品
- 核对生产日期与保质期

**陷阱四：生鲜的运输损耗**
- 生鲜品类看**物流评价**（保冷、破损率）多于产品评价
- 冷链断裂是主要风险

## 服饰 / 鞋 / 包（风格类）

**本品类特殊：文字评价信息量天然不足，且平台多受限。**

### 处理原则
1. **主动说明局限**：这类商品的观感、版型、手感难以通过文字判断
2. **建议线下优先**：能试就试
3. **线上购买时，重点检索三类反馈**：
   - **版型**："偏大""偏小""显胖""显瘦""肩宽"
   - **材质**："手感""厚度""起球""掉色""缩水"
   - **色差**："实物颜色""和图片不一样"
4. **关注退货政策**：风格类退货概率高，重点看退货运费谁承担

### 核心陷阱

**陷阱一：模特图与实物的差距**
- 看**买家秀**而非模特图
- 注意拍摄角度、光线、修图

**陷阱二：尺码标准混乱**
- 不同品牌尺码差异大，不能按习惯尺码买
- 看**具体的身高体重对照反馈**

**陷阱三：面料成分做文章**
- "纯棉"看具体百分比
- 混纺比例影响手感与耐用性

### 降级方案
本品类是**截图协作最主要的使用场景**。请用户提供"问大家"、买家秀、差评截图。

## 大件耐用消费品（汽车用品 / 家具 / 床垫 / 建材）

### 核心陷阱

**陷阱一：决策周期长，信息衰减快**
- 大件产品更新慢，但价格波动大
- 结论要标注信息时间

**陷阱二：安装与售后是主要痛点**
- 家具、建材的**安装服务**和**售后响应**比产品本身更容易出问题
- 重点检索安装体验与售后处理速度

**陷阱三：退换货成本极高**
- 大件退货物流成本高，实际退货率低
- 买错代价大，决策要更慎重

**陷阱四：线下与线上型号不同**
- 家电家具常有线上线下不同型号，"线下同款"往往是不同的产品
- 核对具体型号

### 输出要求
本品类建议先线下体验再线上比价，结论中应明确提示这一点。

## 耗材类（打印机 / 剃须刀 / 净水器 / 咖啡机）

**核心原则：看长期使用成本，不看机器价格。**

- 算**单次使用成本**：`耗材价格 ÷ 使用次数`
- 打印机：机器可能亏本卖，靠墨盒赚钱。算每页成本
- 剃须刀：算刀头单价与寿命（刀头年成本可能超过机身）
- 净水器：算滤芯年成本
- 咖啡机：算单杯成本，兼容胶囊的可用性

**陷阱**：厂商用专有耗材（芯片锁定、物理接口限制）锁定用户，第三方耗材不可用。购买前确认**能否使用兼容耗材**。

## 使用本文件的纪律

1. **小抄是检查清单，不是结论。** 它告诉你去查什么，不告诉你怎么判定。判定仍需依赖实际检索到的证据。
2. **品类归属可能交叉。** 例如"智能手表"既是数码也是健康设备，应按更严格的标准（健康相关）处理。
3. **不要把小抄当知识炫技。** 用户要的是他的决策，不是品类百科。只输出与用户需求相关的要点。
4. **小抄需要持续补充。** 遇到新的品类陷阱时，追加到此文件。
