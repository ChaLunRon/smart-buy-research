## 零、垃圾信息源黑名单（最重要，先读这一节）

**这一节存在的意义是防止重犯历史错误：曾因引用门户聚合内容作为依据而被用户指出偏颇。**

### 硬性黑名单

| 来源 | 问题 | 处理 |
|---|---|---|
| **今日头条 / 微头条** | SEO 内容农场。数码消费类文章多为洗稿、拼凑、AI 批量生成；为搜索排名而写，不是用户口碑 | **默认不作为依据** |
| **百家号** | 同上，标题党严重 | 同上 |
| **搜狐号 / 网易号 / 新浪看点 / 企鹅号** | 自媒体分发平台，流量号为主 | 同上 |
| **"XX 排行榜""XX 十大品牌"页面** | 联盟营销页，按返佣排序 | 同上 |
| **聚合站**（xx评测网、指南师、查查网、知识百科类） | 无原作者、AI 拼接、数据无出处 | 同上 |
| **仿冒站**（如"XX值得买"蹭名站） | 与正主无关，内容多为导流 | 同上 |
| **AI 生成的"经验分享"** | 句式工整、无具体时间地点、无个人细节、无评论互动 | 同上 |

### 判断方法（满足两条以上即判为垃圾源）

1. 页面无作者署名
2. 无发布时间，或发布时间与内容明显不符
3. 无评论互动
4. 正文像产品说明书或论文，不像人在说话
5. 结尾挂购买链接/优惠码/联系方式
6. 通篇没有一句具体的个人使用细节

### 为什么这个问题严重

**门户/聚合内容不是"略微不可靠"，而是方向性错误。** 它们的内容组织逻辑是"如何被搜到"，不是"如何反映真实体验"。用它们做依据，等于把 SEO 运营的产物当成用户共识——**结论会看起来很像样，但依据是空的**。

**典型失真场景**：查某类商品时，多次搜索的头部结果大半来自门户内容农场，直接采用即导致结论偏颇。凡出现"头部结果集中于单一门户平台"的情形，必须重搜换源。

### 黑猫投诉 / 12315（**实测最高价值来源，与垂直社区并列第一优先**）

- **为什么比测评文章硬**：测评只能告诉你"评价如何"，投诉平台能告诉你**到底哪里坏了、什么时候坏的、商家怎么处理的** —— 有日期、有金额、有型号、有故障描述
- **适合挖**：售后纠纷、批量质量问题、厂商处理态度、具体故障现象与时间线
- **检索技巧**：
  - **看具体案例，不是看数量**。一条详实的案例胜过一百条统计
  - **看投诉解决率**而非投诉数量；大品牌销量大，投诉绝对数自然高
  - 搜 `{品牌} 黑猫投诉` `{型号} 投诉`，按时间排序看近期
  - 关注**厂商回复了什么、有没有实际解决** —— 这本身就是售后质量的证据
- **可信度基准**：★★★★★
- **特别提醒**：投诉内容需甄别（有恶意投诉），但**同一问题反复出现是强信号**

**典型收获**：某机型可从黑猫投诉挖到多起实案，给出"两分钟掉 1% 电""两月内三次黑屏""主板两次更换"这类具体记录 —— 直接成为结论的核心依据。

**三包时限与换货窗口**：**收货 15 天内是换货窗口**（7 日内性能故障可退货、15 日内可换货、三包期内同一故障两次维修仍不能用可换货或退货）。商家常用"超过 7 天无理由"混淆"三包质量问题退换"，收货后应尽快重度使用测试。详见「价格与渠道」文件。

## 二、电商平台

| 平台 | 优势 | 检索技巧 | 注意 |
|---|---|---|---|
| 淘宝 / 天猫 | 品类最全，中小品牌多 | 看"问大家"板块（真实买家问答，难以控评）；筛选"追评"看长期使用 | "问大家"是电商平台里最接近真实的信息源 |
| 京东 | 自营售后规范，物流快 | 看自营 vs 第三方；看"商品评价"中的差评与追评 | 自营与第三方的售后责任主体不同 |
| 拼多多 | 价格低 | 注意"百亿补贴"是否有官方授权；查店铺资质 | 白牌与山寨风险高，"电商专供款"多 |
| 抖音商城 | 直播带货 | 注意直播话术夸大 | 冲动消费风险高，慎选 |
| 唯品会 | 品牌特卖 | 注意是否当季款 | 部分为过季或特供款 |
| 苏宁 / 国美 | 家电 3C | 适合大件家电比价 | — |

**电商评价的读法（关键）**：
- **"问大家"优先级最高** —— 买家回答买家问题，商家难以系统性控评
- **追评优先于首评** —— 首评多为开箱情绪，追评才有使用后的真实判断
- **差评要读全文** —— 很多差评是物流问题（与产品无关），要区分"产品问题"和"服务问题"
- **看差评率而非差评数**

## 四、国际独立源

**为什么需要这一层**：国内电商好评率天然虚高（常见 99%），社交平台营销污染重。国际独立测评源通常有更严格的利益披露机制和更硬的数据。

| 来源 | 领域 | 用途 | 可信度 |
|---|---|---|---|
| Reddit | 全品类 | 海外真实讨论，几乎无国内营销污染；r/BuyItForLife、r/headphones 等垂类版块质量很高 | ★★★★☆ |
| Labdoor | 保健品 | 独立实验室实测成分含量与重金属，非厂商送检 | ★★★★★ |
| ConsumerLab | 保健品/食品 | 独立测试，付费但结论公开 | ★★★★★ |
| IFOS | 鱼油/omega-3 | 专项认证与批次检测报告 | ★★★★★ |
| Trustpilot | 海外品牌 | 品牌级口碑（注意仍可能有刷评） | ★★★☆☆ |
| Wirecutter / Consumer Reports | 全品类 | 老牌独立评测，方法论严谨 | ★★★★☆ |
| Which?（英国） | 全品类 | 消费者组织独立测试 | ★★★★☆ |
| Amazon Reviews（海外站） | 全品类 | 用 Fakespot 类工具过滤刷评后再读 | ★★★☆☆ |

**使用纪律**：
- 国际源的结论**不能直接套用到国内版本**。同一品牌在不同市场的产品线、代工厂、配方可能完全不同
- 主要用于**验证品牌级声誉**（这个品牌在全球范围内是否有质量争议）和**验证成分/技术宣称**（厂商说的技术是不是真的）
- 保健品、海外品牌、有国际对照的品类优先使用

## 五、平台访问限制与降级路径

**以下平台有反爬、登录墙或访问限制，检索工具可能读不到页面内容。**

| 平台 | 限制情况 | 替代路径 |
|---|---|---|
| 小红书 | **IP 级风控**，浏览器也读不到 | 换 B站/贴吧/豆瓣；请用户截图笔记与评论 |
| 拼多多 | 常见访问受限 | 请用户截"问大家"与差评；转京东/天猫比同款 |
| 淘宝/天猫 | 商品页常受限 | 换京东自营；请用户截图"问大家" |
| 知乎 | 部分内容需登录 | 换检索摘要；换 B站对应内容 |
| 什么值得买 | 价格页可能受限 | 请用户截价格爆料；换其他比价渠道 |
| 微博 | 部分需登录 | 换超话入口；换投诉平台 |

**处理纪律**：
1. **不要假装成功。** 读不到就说读不到，不要凭搜索引擎标题推测内容
2. **先换源，再换形态，然后无头浏览器，最后才请用户截图**
3. **多数情况换源就能解决。** 同一问题在 B站/贴吧/豆瓣/黑猫投诉里往往都有讨论

> 具体获取方案（无头浏览器 / B站 API / 微信公众号直连 / MediaCrawler / 电商比价工具）见「抓取实操方案」文件。截图协作的完整清单见 SKILL.md「降级方案」。

### 使用纪律

- **样本量小但信息密度高** —— 适合验证技术细节，不适合判断大众口碑
- **正确用法**：垂直社区判断"技术上好不好"，综合平台判断"用起来怎么样"，两者交叉
- **英文品类加 "forum" "community" "subreddit"** 往往能找到量化测试质量更高的社区

## 七、检索策略

### 跳出商业内容池

搜索结果前几页往往被 SEO 优化的商业内容占据。跳出方法：
1. **改变关键词的情绪色彩**：加"后悔""避雷""智商税""翻车""维权"
2. **站内搜索**：直接进垂直社区站内搜，绕开搜索引擎的商业排序
3. **按时间排序**：商业长文的权重会随时间衰减，"最新"更接近真实
4. **搜索长尾问题**：搜 `{型号} 用了一年` `{型号} 故障` 而非 `{型号} 评测`
5. **搜索负面组合**：`{品牌} 投诉` `{品牌} 售后` `{品牌} 骗局`
